# Урок 0 – Ставим инструменты

**Цель:** редактор и Claude Code (или Codex) установлены, подписка оплачена, AI отвечает на «привет».

---


## Если вы из России

Держите VPN включённым всё время, пока работаете с AI, а не только при регистрации. Включили VPN, потом открыли редактор. Если VPN выключится посреди работы, аккаунт могут заблокировать, поэтому пусть он будет включён постоянно и на одной и той же стране.

Как зарегистрироваться и оплатить из России (какая страна, номер для SMS, какая карта подходит) – в Шаге 1 ниже.

---


## Шаг 1: Подписка на AI

Покупаем **одну** подписку: или Claude (рекомендуем), или ChatGPT.

| Что покупаем | Цена | Где оплатить |
|---|---|---|
| Claude Max (курс будет на этом примере) | $100/мес | https://claude.com/account → Plans → Max |
| ChatGPT-подписка с доступом к Codex | от $100/мес | https://chatgpt.com → Settings → Subscription |

На младших планах ($20/мес у Claude Pro и ChatGPT Plus) лимиты заканчиваются за 30–60 минут активной работы. Для курса этого мало.


### Если вы из России

Сервис не открывается, регистрация падает с ошибкой региона, российские карты не принимаются. Антифрод любит, когда страна карты, VPN и номера телефона совпадают. Поэтому начинаем с карты: она задаёт страну, а уже под неё подбираем VPN и номер.

1. **Сначала выберите способ оплаты.** От него зависит, какую страну вы будете использовать дальше. Что работает:
   - **Реальная зарубежная карта** (Казахстан, Армения, Грузия, Сербия, Турция, ОАЭ, Израиль). Самый надёжный путь.
   - **Карта знакомого за рубежом**, часто надёжнее посредников.
   - **«Плати по миру» / «Платим по миру»** – сервис-посредник, бот в Telegram: @platipomiru_bot. Часто проходит, но иногда платёж блокируют и возвращают деньги. Тогда придётся ждать возврат и оформлять новую карту.
   - **ForeignPay** – оплачивает подписку **ChatGPT** (для Claude не подходит, Claude там нет). Ссылка для оплаты: https://foreignpay.ru/products/business/ChatGPT

   **Не работает:** GGSell, Zarub, migpaybot, готовые аккаунты с маркетплейсов, криптокарты, подарочные подписки. Высокий риск бана или невозможности восстановить аккаунт.

2. **Включите VPN на страну вашей карты.**

3. **Купите иностранный номер для SMS в той же стране для Claude Code.**
   https://app.cyberyozh.com/ru/reception-sms/. Альтернативы: https://hero-sms.com, https://smsfast.guru. Номер нужен один раз, при подтверждении регистрации Claude Code.

4. **Зарегистрируйтесь при включённом VPN.**
   Для Claude: https://claude.ai/signup. Для ChatGPT: https://chatgpt.com/auth/signup.

## Шаг 2: Редактор

Поставьте **VS Code**: https://code.visualstudio.com (бесплатно). На курсе все примеры будут в VS Code.
Cursor или Antigravity (вне России) тоже подойдут, они сделаны на основе VS Code. Но встроенным AI от них мы пользоваться не будем.

---


## Шаг 3: Создаём проект

Проект – это просто папка на компьютере, где лежат все файлы. Сейчас её создадим.

1. Откройте VS Code. В меню выберите **File → Open Folder** (Файл → Открыть папку).
2. Создайте новую папку и назовите её `vibe-coding-course`. Откройте её – это и есть ваш проект.
3. Внутри `vibe-coding-course` создайте папку `lessons`.
4. К этому уроку прикреплена папка `lesson-00-setup`. Скачайте её и положите внутрь `lessons`.

Должно получиться так:

```
vibe-coding-course/
└── lessons/
    └── lesson-00-setup/
```

Дальше каждый урок будете складывать в `lessons` рядом: `lesson-01-product`, `lesson-02-design` и так далее.

## Шаг 4: Плагин для AI

Плагин в VS Code зависит от того, какую подписку оплатили в Шаге 1.

| Оплатили | Плагин | Имя в Extensions |
|---|---|---|
| Claude Max | Claude Code | «Claude Code» |
| ChatGPT с Codex | OpenAI Codex | «OpenAI Codex» (автор – OpenAI) |

1. Откройте панель Extensions (`Ctrl/Cmd+Shift+X`), найдите нужный плагин по имени из таблицы, нажмите Install.
2. В левой панели VS Code появится иконка инструмента. Откройте её.
3. Нажмите Sign in – откроется браузер, войдите в тот же аккаунт, под которым оплатили подписку.

**Проверка:**
- В VS Code видна боковая панель Claude Code или Codex.
- После авторизации панель перестала просить войти.

---


## Шаг 5: Тестовый промт

В боковой панели плагина напишите:

```
Привет! Расскажи, что ты умеешь и чем ты отличаешься от обычных ChatGPT/Claude.
```

Нажмите Enter. AI ответит в этой же панели.

Теперь второй промт – он покажет главное отличие на деле:

```
Посмотри, сколько и каких файлов лежит у меня в папках «Загрузки» и «Рабочий стол».
```

Обычный ChatGPT в браузере так не умеет – он не видит ваш компьютер. А плагин видит: откроет эти папки, посчитает файлы и расскажет, что в них. Это и есть разница – AI работает прямо с вашими файлами.

## Шаг 6: Голосовой ввод

Без диктовки длинные интервью с AI на курсе превращаются в долгий набор текста. С голосовым вводом ответ занимает 30 секунд вместо 3 минут. Это особенно важно для PRD-интервью в Уроке 1.

Поставьте один из инструментов:

- **Spokenly** (macOS, бесплатно) – https://spokenly.app/. Нужен бесплатный Groq API-ключ из https://console.groq.com → API Keys (выглядит как `gsk_...`). В Spokenly: Dictation Model → вкладка **API** → Groq → вставьте ключ → назначьте хоткей.

  > Во вкладке Online тоже есть Groq, но там расшифровка идёт через тариф Spokenly. Берите именно API – быстрее и качественнее.

- **WisprFlow** (macOS / Windows, бесплатный пробный период) – https://wisprflow.ai. Установили, назначили хоткей, работает. Отдельный API-ключ не нужен.

- **Handy** (macOS / Windows / Linux, бесплатный, открытый) – https://handy.computer. Работает офлайн, прямо на вашем компьютере, без ключа. Распознаёт чуть хуже первых двух, зато полностью бесплатный и не отправляет голос в облако. Берите, если не хотите платить.

**Проверка:** в поле ввода Claude Code или Codex зажмите хоткей, скажите «Привет, что ты умеешь?», отпустите. Текст вставится в поле.
