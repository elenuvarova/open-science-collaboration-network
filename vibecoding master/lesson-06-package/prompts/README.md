## Что под продукт

Монорепо, лендинг и SEO (`00`–`05`) можно пропустить, если у продукта нет публичной аудитории. Размещение приложения (`03`) решают все: дефолт — подстраница `/app`, поддомен `app.` берут при необходимости. PWA (`08`) — по необходимости. Юридические страницы (`07`) нужны всем, кто собирает данные (а аналитика из `06` их собирает). Финальный прогон перед запуском (`09`) стоит сделать всем. Защита от регрессий, консолидация памяти и сборка библиотеки модулей — в финальном Уроке 7.
