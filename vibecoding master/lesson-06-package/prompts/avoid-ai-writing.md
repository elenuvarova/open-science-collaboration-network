# Текст без AI-следов — вычитка копирайта лендинга

> **Universal markdown.** Этот файл написан так, чтобы любой AI (Claude Code, Codex, Cursor) прочитал его и выполнил пошагово. Платформенных зависимостей нет.
>
> В Claude Code, если установлен скилл, можно вызвать `/avoid-ai-writing` — это та же методология. Если скилла нет (или работаешь в Codex/Cursor) — выполняй по этому файлу.

Цель: убрать из текстов лендинга признаки AI-генерации, чтобы копирайт звучал как от живого человека, который знает продукт и сегмент из брифа, — а не как «нейросеть вообще про SaaS». Дизайн может быть нешаблонным, но AI-текст всё равно выдаёт штамповку.

## Когда применять

Когда лендинг собран и тексты уже на странице (`page.tsx`): Hero, подзаголовки, Features, блок «для кого», How it works, FAQ, CTA. Прогоняем именно копирайт, не код.

## Профиль — `landing`

Для лендинга работаем строже обычного: промо-язык и «инфляция значимости» — главные враги. Текст продаёт фактами из брифа, а не громкими словами без доказательства.

## Два режима

- **`rewrite`** (по умолчанию) — найти AI-маркеры → переписать → показать diff → второй проход для проверки.
- **`detect`** — только найти и пометить (когда текст нельзя менять или нужна быстрая проверка).

## Алгоритм

1. Собери все тексты лендинга из `page.tsx` (и связанных компонентов Hero/Features/FAQ).
2. Прогони по чеклисту ниже (минимум P0 + P1).
3. Перепиши найденное, опираясь на факты из `../../product/docs/landing-brief.md` (конкретная job, результат, числа, возражения).
4. Покажи diff: было → стало, с пометкой какой паттерн убран.
5. Второй проход: не появились ли новые штампы при переписывании.

## Чеклист

### P0 — убираем сразу

- [ ] Артефакты чат-бота: «Конечно!», «Отличный вопрос!», «Надеюсь, это поможет».
- [ ] Заявления без доказательства: «гарантированный результат», «100% эффективность», «№1 на рынке» без подтверждения.
- [ ] Инфляция значимости на ровном месте: «революционный», «поворотный момент», «меняет всё».

### P1 — убираем до публикации

**Слова-маркеры (RU):** «в современном мире», «на сегодняшний день», «ключевой момент», «комплексный подход», «тщательно подобранный», «инновационное решение», «выводит на новый уровень». В одном абзаце — максимум одно из «благодаря / обеспечивает / позволяет / способствует / направлен на».

**Конструкции:**
- [ ] Антитеза «не X, а Y» / «это не просто …, это …» — максимум одна на весь лендинг, остальное переформулировать утвердительно.
- [ ] Открытия-затычки: «давайте рассмотрим», «в этой статье/на этой странице мы…».
- [ ] Тройные перечисления «быстро, удобно и надёжно» — оставляем только то, что реально несёт смысл.
- [ ] Симметричные формулы «чем глубже X, тем точнее Y».
- [ ] Однотипные заголовки секций под копирку.

**Промо-язык (для лендинга — строго):**
- [ ] «команда профессионалов», «опытные специалисты» → конкретика (кто, сколько, какой опыт).
- [ ] «индивидуальный подход» → что именно индивидуального.
- [ ] «современное оборудование/технологии» → конкретный тип/название.
- [ ] «динамично развивающийся», «процветающий» → факт или вон.

**Открытие Hero:**
- [ ] Не начинать с «В современном мире…» / «На сегодняшний день…».
- [ ] Первое предложение — конкретика (что за продукт + job + результат), а не общий контекст.

### P2 — полировка

- [ ] Длина предложений варьируется: есть и короткие (3-8 слов), и длинные (20+). Не всё одной длины.
- [ ] Em-dash (—) в прозе — не злоупотреблять (в bullet-списках `**Имя** — описание` нормально).
- [ ] Жирный — дозированно, не на каждой второй фразе.
- [ ] Эмодзи в заголовках — нет.
- [ ] Финал секций конкретный (вывод или CTA), без «оставайтесь с нами» и «время покажет».
- [ ] Переходы «более того / кроме того / также» — по делу, не как scaffolding.

## Read-aloud тест (финал)

Прочитай вслух 2-3 случайных блока. Если звучит как презентация на конференции или брошюра турагентства — переписать. Если как живой разговор человека, который знает продукт, — ок.

## Когда переписывать с нуля, а не патчить

Если совпало всё: 5+ слов-маркеров, 3+ типа шаблонных конструкций, однородный ритм — не патчь, перепиши блок заново. Сначала одна фраза с главной мыслью (из брифа), потом текст вокруг неё.

## Результат

Тексты лендинга переписаны: Hero, Features, FAQ звучат живо и конкретно из брифа, без пустых промо-фраз, антитез-шаблонов и AI-маркеров. Показан diff было → стало.
