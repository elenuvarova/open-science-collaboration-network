# Выбор ORM (Prisma vs Drizzle) — ADR-003 (опционально)

> **Опционально.** По умолчанию курс прикручивает Prisma автоматически на шаге со схемой (Задание 3) — отдельно ORM выбирать не нужно. Этот промт — для тех, кто хочет осознанно сравнить Prisma и Drizzle и, возможно, взять Drizzle. Если такого желания нет, пропустите: дефолт Prisma уже записан в ADR-003 при выборе базы.

> **Цель:** при желании — осознанный выбор Prisma vs Drizzle, дописанный в раздел «ORM» того же `ADR-003-data-layer.md`, с обоснованием отвергнутой альтернативы.

Сравнительная таблица:

| | Prisma | Drizzle |
|---|---|---|
| Зрелость | Стабильная, много пользователей | Молодая, активно растёт |
| Типы | Auto-generated client из schema.prisma | Из TS-схемы |
| SQL | Скрыт за абстракцией | Очень близко к SQL |
| Миграции | prisma migrate (декларативные) | drizzle-kit (декларативные) |
| Перформанс | Чуть медленнее (генерация SQL) | Близко к raw SQL |
| AI-помощь | Очень много примеров в обучающих выборках | Меньше, но растёт |
| Edge runtime | Сложнее (Prisma Client тяжёлый) | Из коробки |

### Голый SQL через pg-клиент
**Отвергли:** нужно знать SQL глубоко, нет миграций из коробки, нет типов
автоматом — для дизайнера слишком высокий вход.

### TypeORM / Sequelize
**Отвергли:** устарели по сравнению с Prisma/Drizzle, у Claude меньше "опыта" в
обучении, развитие медленнее.

**Отвергли:** теряем типы, миграции, защиту от SQL injection через placeholders.
Слишком хрупко для прода.

## Edge cases

- Если у пользователя уже есть опыт SQL — Drizzle может быть приятнее (ближе к SQL)
- Для большинства проектов по умолчанию **Prisma — оптимальный выбор**: больше примеров в обучении AI, более «толстая» абстракция, скрывающая SQL
