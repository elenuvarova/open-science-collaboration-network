# AI через прямой API — OpenRouter

Встраиваем AI как функцию продукта: сервер ходит к модели через один API-ключ и показывает ответ пользователю.

> **Сначала разбор фичи, потом код.** AI-фичи — сложный кусок продукта. Прежде чем писать код, продумайте с пользователем _все_ AI-фичи из `spec.md` (не только первую): что именно делает каждая, как работает, какой нужен функционал, что за чем идёт и какая модель ей подходит по цене/качеству. В Claude Code это делает скилл `/new-feature` (интервью → бриф → реализация); если скилла нет (Codex/Cursor/другой AI) — задай пользователю уточняющие вопросы по `spec.md` и покажи план, и только после согласования реализуй.

## Почему OpenRouter, а не прямой Anthropic / OpenAI API

- **Один ключ → много моделей.** Claude, GPT, Gemini, а также дешёвые DeepSeek, Kimi, Qwen, Llama — всё через один endpoint
- **Прозрачная стоимость.** Видно расход в личном кабинете, легко переключать модели
- **Не привязан к одному вендору.** Если завтра Anthropic ушёл — переключаешь на GPT одной строкой
- **Подписка не нужна.** Pay-as-you-go, минимальное пополнение $5–10

## Сколько денег закладывать на тесты

- **$10** — отладка + первые фичи в продукте (~500 запросов к Claude Sonnet)
- **$30–50/мес** — небольшой production-трафик
- Дальше масштабируется с пользователями

## Реализация

### Шаг 1 — Получить ключ

Попроси пользователя:

1. Зайти на https://openrouter.ai

2. Зарегистрироваться, пополнить баланс на $10 (минимум на тесты)

3. Создать API-ключ в Settings → API Keys, скопировать его

Положи ключ в env-файл (НЕ в чат, НЕ в терминал). Сам создай (или дополни) файл с плейсхолдером:
- локальная разработка → `.env.local`, строка `OPENROUTER_API_KEY=впиши-сюда-свой-OpenRouter-ключ`
- прод → `.env.production`, та же строка

Скажи пользователю: «Я создал `.env.local`. Открой его и впиши ключ после `OPENROUTER_API_KEY=` вместо плейсхолдера, сохрани». Пользователь вписывает ключ прямо в файл, ни в терминал, ни в чат вводить ничего не нужно, и ты значение ключа не видишь. Подключение к OpenRouter ты делаешь сам, читая ключ из env через `process.env.OPENROUTER_API_KEY`. Файлы `.env.local` и `.env.production` уже в `.gitignore`, в git не попадут.

### Шаг 2 — API route

```ts
// ../../product/src/app/api/ai/route.ts
export async function POST(req: Request) {
  const { prompt } = await req.json()
  
  const response = await fetch('https://openrouter.ai/api/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.OPENROUTER_API_KEY}`,
      'Content-Type': 'application/json',
      'HTTP-Referer': 'https://your-domain.com',
      'X-Title': 'Your Product Name',
    },
    body: JSON.stringify({
      model: 'anthropic/claude-sonnet-4-6',
      messages: [{ role: 'user', content: prompt }],
    }),
  })
  
  const data = await response.json()
  return Response.json({ result: data.choices[0].message.content })
}
```

### Шаг 3 — Безопасность

- Ключ **только** в `.env` на сервере, никогда не во frontend
- Все вызовы AI идут через бэкенд (Next.js API route)
- Rate limit на `/api/ai/*` (через middleware или Upstash Redis)
- Лимит расхода на пользователя/день — поле `aiUsage` в `User` модели
- Логирование запросов и ответов в БД для аналитики и audit

### Шаг 4 — AI-фичи

Реализуй все AI-фичи из `spec.md` (не только первую) — классификация, генерация, перевод, суммаризация, чат-ассистент и т.п. Под каждую подбери модель по принципу из раздела «Выбор модели» (простое/массовое → дешёвая, сложное → топовая).

## Выбор модели

Сначала предложи пользователю варианты под его фичи с компромиссом цена/качество — он выберет. Правило: **не каждой фиче нужна дорогая модель.**

**Топовые (для сложного — рассуждения, длинные ответы, качество важно):**
- `anthropic/claude-sonnet-4-6` — баланс качества/цены, хорош для большинства задач
- `anthropic/claude-opus-4-7` — максимум качества, дорого
- `openai/gpt-4-turbo` — альтернатива, иногда лучше на code-tasks
- `google/gemini-2-pro` — длинный контекст

**Дешёвые (для простого/массового — классификация, теги, короткие ответы; в разы дешевле):**
- `anthropic/claude-haiku-4-5` — быстро и дёшево от Anthropic
- `deepseek/deepseek-chat` — очень дёшево, достойное качество
- `moonshotai/kimi-k2` — дёшево, длинный контекст (Kimi)
- `qwen/qwen-2.5-72b-instruct` — дёшево, хорошо для текста
- `meta-llama/llama-3.3-70b-instruct` — открытая, дёшево

Точные id моделей и актуальные цены проверь на https://openrouter.ai/models — каталог меняется. В коде выбор модели через env-переменную (можно завести разные под разные фичи):
```
OPENROUTER_MODEL=anthropic/claude-sonnet-4-6
OPENROUTER_MODEL_CHEAP=deepseek/deepseek-chat
```

Это позволяет переключать модель без правки кода: дорогую — туда, где нужно качество, дешёвую — на простые и массовые вызовы.

## Принцип «AI объясняет, скрипт считает»

Числовое (суммы, балансы, подсчёты) считаем в SQL/коде; AI доверяем текстовое — пересказ, классификацию, генерацию.
