# Промты — интеграции и расширения (опциональные надстройки)

| Файл | Шаг | Когда использовать |
|---|---|---|
| `01-ai-openrouter.md` | 1 | Внешний AI в продукте через OpenRouter |
| `02-admin.md` | 2 | Админка: управление контентом + страница логов + обзор с метриками |
| `03-rest-api.md` | 3 | REST API + API-ключи для интеграций (зачем и как; примеры — n8n и т.п.) |
| `04-telegram-bot.md` | 4 | Telegram-бот: оповещения владельцу (только исходящие, без webhook) |
| `04b-uptime-monitoring.md` | 4 | Uptime-мониторинг — алерт владельцу, если сайт недоступен (через тот же бот или внешний сервис) |
| `05-security-check.md` | финал | Security-аудит после всех расширений |

> **Ядро продукта собрано в Уроке 4** — туда перенесены вещи, которые «должны работать сразу»:
> - **email** — письма аккаунта и продуктовые (инвайты, заказы, дайджест);
> - **центр уведомлений** — `notify`, колокольчик, `/notifications`, мьют типов (только in-app; email — отдельные транзакционные письма);
> - **файлы/хранилище**.
>
> Этот урок — **опциональные надстройки**, которых может вообще не быть в продукте.

## Что не нужно — пропустить

Берём только то, что нужно продукту. Нет в `spec.md` (Telegram-алерты, REST наружу, AI) — пропускаем шаг. А ядро (уведомления, email, файлы) уже собрано и проверено в Уроке 4 — здесь не дублируем.
