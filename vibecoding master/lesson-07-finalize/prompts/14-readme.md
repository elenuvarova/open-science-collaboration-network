# Урок 7 — Промт 10: README — точки входа в сервис

> **Цель:** у сервиса есть корневой `../../product/README.md` (что за продукт, как запустить, карта документации) и короткие `README.md` в ключевых папках (`../../product/docs/`, `../../product/development/apps/app/src/`, `../../.claude/`, `../../modules/`, `../../product/development/packages/ui/`). Каждый README — указатель «что здесь и куда идти за деталями», а не копия спеки.

---

## Зачем это (прочитай сам перед запуском)

README — это первая дверь в папку. Когда в репозиторий заходит новый человек или AI открывает незнакомую папку, README — первое, что читают. Без него каждый раз приходится заново объяснять «что это, с чего начать, куда смотреть».

- **Для человека.** Вернулись к проекту через 2 месяца — README за минуту напоминает, как запустить и где что лежит. Пришёл второй разработчик — не дёргает вас по каждому «а это что за папка».
- **Для AI.** Перед тем как трогать файлы в папке, AI читает её README. Это снижает число ошибок: он не выдумывает структуру заново и не кладёт файл не туда. README в папке работает как локальная инструкция — дешевле, чем держать всё в одном большом `CLAUDE.md`.
- **README ≠ spec.** Спека описывает поведение продукта. README — это карта-указатель: что лежит в этой папке, зачем она нужна, как её менять и куда идти за деталями (ссылки на `spec.md`, `screens/`, `memory/INDEX.md`). Никакого дублирования — только навигация.

Принцип: **в каждой значимой папке — свой короткий README.** Тогда и человек, и AI входят в любую часть сервиса через понятную дверь.

---

## Промт


## Edge cases

- **README уже есть.** Не затирай вслепую — дополни недостающие разделы, сохрани то, что человек писал руками.
- **Папки нет** (`modules/`, `shared/ui/`) — пропусти соответствующий README, не создавай пустышку.
- **Монорепо / несколько сервисов** — корневой README описывает общую раскладку, плюс свой README на каждый сервис.
- **Приватные данные** — в README не должно быть секретов, токенов, паролей. Только публичная навигация.
- **Не дублируй spec.** Если тянет переписать в README поведение экрана — остановись и поставь ссылку на `docs/screens/<screen>.md`.
