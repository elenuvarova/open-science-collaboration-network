# UX-аудит прототипа — найти всё что не работает перед переходом к данным

> ⛔ **Этот этап — только локальный запуск, без выкладки наружу.** Единственный «запуск» здесь — `npm run dev` у тебя на компьютере (это разрешено и нормально). Нельзя: разворачивать приложение на хостинг/сервер (Vercel / Netlify / Render / VPS), подключать git-remote / GitHub, делать `git push`, запускать деплой-скиллы или предлагать деплой. Если кажется, что «ничего не задеплоено» — так и задумано: публикация в интернет, git и GitHub — отдельно, в Уроке 3.

Этот промт запускается **после генерации всех экранов** (промты 04–07) и **до этапа деплоя**. Цель — найти и закрыть все «дыры»: кнопки без обработчиков, экраны без входа, тупики без выхода, заглушки. С поломанным UX двигаться дальше нельзя.

**Предусловие:** все экраны из `../../product/docs/spec.md` реализованы и запущены через `npm run dev`.

---

## Шаг 0 — Сканирование всех экранов

Прочитай проект, определи фреймворк из `spec.md` (стек) и собери полный список страниц.

**Next.js App Router:**
```bash
cd ../../product
find src/app -name "page.tsx" -not -path "*/node_modules/*" | sort
```

**React Router (routes.tsx / router.tsx):**
```bash
cd ../../product
grep -rE 'path=["'"'"'][^"'"'"']+["'"'"']' src/ --include="*.tsx" --include="*.ts" | grep -v node_modules
```

Составь таблицу:

| URL | Файл | Доступ |
|---|---|---|
| `/` | `src/app/page.tsx` | все |
| ... | ... | ... |

Если список пустой или найти не удалось — спроси пользователя: «Где лежат файлы страниц? Покажи структуру `../../product/src/`».

## Шаг 1 — Быстрый скан (запустить одним блоком)

```bash
cd ../../product
echo "=== ПУСТЫЕ ОБРАБОТЧИКИ ===" && \
grep -rn "onClick=\{[()=>\s]*\}\|onClick=\{undefined\}" src/ --include="*.tsx" 2>/dev/null | head -20

echo -e "\n=== ЗАГЛУШКИ ===" && \
grep -rn "TODO\|FIXME\|coming soon\|Coming Soon\|заглушка\|будет позже\|в разработке\|placeholder text" \
  src/ --include="*.tsx" --include="*.ts" 2>/dev/null | head -20

echo -e "\n=== КНОПКИ БЕЗ ДЕЙСТВИЯ ===" && \
grep -rn "<Button\b" src/ --include="*.tsx" 2>/dev/null | grep -v "onClick\|href\|type=\"submit\"\|asChild" | head -20

echo -e "\n=== ССЫЛКИ И ПЕРЕХОДЫ ===" && \
grep -rn "<Link\|router\.push\|router\.replace\|href=" src/ --include="*.tsx" 2>/dev/null | grep -v node_modules | head -30
```

Сохрани вывод — он нужен для Шага 2.

## Шаг 2 — Проверка каждого экрана по 5 пунктам

Для каждого экрана из таблицы (Шаг 0):

### 2.1 Точки входа — кто ссылается на этот экран?

```bash
cd ../../product
# Замени /target-url на реальный URL экрана
grep -rE '(href|to|push|replace|redirect)=["\x27]/target-url' src/ --include="*.tsx" --include="*.ts"
```

🔴 **Проблема:** экран есть, но никто на него не ссылается → «призрак». Либо добавить ссылку (навигация, кнопка, редирект), либо удалить экран.

### 2.2 Точки выхода — есть ли навигация с экрана?

```bash
cd ../../product
grep -nE '(<Link|href=|router\.push|router\.replace|redirect\(|navigate\()' src/app/TARGET_PATH/page.tsx
```

🔴 **Проблема:** с экрана нет ни одного пути выхода → тупик.

### 2.3 Интерактивные элементы — у каждого есть поведение?

```bash
cd ../../product
# Пустые onClick
grep -nE 'onClick=\{[()=>\s]*\}|onClick=\{undefined\}' src/app/TARGET_PATH/page.tsx

# Button без обработчика
grep -nE '<(Button|button)[^>]*>' src/app/TARGET_PATH/page.tsx | grep -v 'onClick\|type="submit"\|href\|asChild'
```

🔴 **Проблема:** кнопка видна, но ничего не делает при клике.

### 2.4 Заглушки и незаконченный контент

```bash
cd ../../product
grep -n "TODO\|FIXME\|coming soon\|Coming Soon\|заглушка\|будет позже" src/app/TARGET_PATH/page.tsx
```

🟡 **Проблема:** экран показан пользователю, но содержит маркеры незаконченного контента.

### 2.5 Состояния — реализованы ли loading/empty/error?

Сверь с `spec.md` раздел «Состояния» для этого экрана:
- `loading` → есть ли Skeleton или Spinner?
- `empty` → есть ли EmptyState с текстом и CTA?
- `error` → есть ли ErrorState с кнопкой «Повторить»?

🟡 **Проблема:** спека описывает состояние, но в коде его нет.

## Шаг 4 — Закрыть критические проблемы

Для каждой 🔴-проблемы исправь до перехода к деплою:

| Проблема | Как исправить |
|---|---|
| Кнопка без onClick | Добавить обработчик или убрать кнопку |
| Orphan screen (нет входа) | Добавить Link в навигацию или на другом экране |
| Тупик (нет выхода) | Добавить Link «Назад» или кнопку с переходом |

После каждого исправления — повторить grep из Шага 1 для проверки.

**Правило:** нельзя переходить к деплою пока в отчёте есть хотя бы одна строка в разделе 🔴.
