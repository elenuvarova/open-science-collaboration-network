## Executive summary

The through-line for Elena (solo EU indie, React18/Vite + Next App Router + Express/FastAPI + Postgres, self-hosted Coolify/Hetzner, trilingual, cost-conscious, GDPR-real): default to Postgres-first and self-host on her existing box for almost everything (queue, search, vector/RAG, realtime, observability, CMS), reaching for managed SaaS only where it clearly earns it (payments MoR, transactional email, and DR copy-2 off-box). ## Stack picks (default per area)

### Payments / billing
**Pick:** Polar (Merchant-of-Record) as default; Stripe Managed Payments as the MoR alternative; Stripe-direct only if she wants to own VAT

Polar is MoR so it files/remits EU VAT and handles B2B reverse charge — exactly what a solo Belgian dev needs to avoid the €10k OSS threshold paperwork. Note the 27 May 2026 Polar repricing (Starter 5%+50¢; pre-date orgs grandfathered 4%+40¢; verify Pro % live). New in 2026: Stripe Managed Payments is also MoR (preview Feb 2026, 5%+$0.50) — so the decision is MoR-provider choice, not Stripe-vs-VAT. Keep app+Postgres entitlement store self-hosted; only checkout/webhooks leave the box (minimal PCI scope).

### Background jobs / queue
**Pick:** pg-boss on her existing Postgres (no new infra)

Postgres-as-queue is the zero-new-container choice and is robust into the hundreds of jobs/sec for a solo app (PlanetScale's 800/s death-spiral was forced in a 15-min test; a tuned cluster does tens of thousands/s). Dashboard is @pg-boss/dashboard. Avoid Dramatiq unless she wants RabbitMQ (its default broker — it is NOT a Redis library). For Python/FastAPI use arq (python-arq org, maintenance-only) or its successor streaQ.

### Realtime / websockets
**Pick:** SSE-first for server→client; Socket.IO when bidirectional; self-hosted on Coolify

SSE covers most needs (HTTP/2 removed the 6-connection limit) and survives Cloudflare proxy. Socket.IO 4.8.x for chat/presence; no Redis adapter needed on a single VPS (add sharded/Streams adapter only when she scales to replicas). For collab use Yjs/Hocuspocus v4 (MIT). Note: Cloudflare proxy_read_timeout is 100s on Free/Pro/Business — only Enterprise raises it (deploy proxy=off per her flow). Liveblocks free tier is now metered, not 50-MAU.

### In-app search
**Pick:** Postgres FTS + pg_trgm → self-hosted Meilisearch on Coolify when she outgrows it

websearch_to_tsquery never throws on user input; add pg_trgm for typo tolerance (FTS only stems). STORED generated tsvector + GIN. Graduate to Meilisearch 1.42+ (MIT core / BUSL enterprise features) for relevance/typo UX. For CDC sync use meilibridge (actively maintained Rust connector), NOT meilisync (dormant since Feb 2024). Hybrid/vector is stable in current 1.x (was experimental in 1.6).

### Vector / RAG
**Pick:** pgvector in her existing Postgres (HNSW, halfvec); self-hosted Qdrant only at millions of vectors + heavy selective filtering

Zero new infra, EU data residency, GDPR-clean. HNSW > IVFFlat in 2026; pgvector 0.8 iterative scans (hnsw.iterative_scan) close much of the filtered-search gap to Qdrant. Use Anthropic Contextual Retrieval (contextual embeddings + BM25 = 49% fewer retrieval failures; +reranking = 67%). For trilingual EN/NL/FR self-host BGE-M3 or Qwen3-Embedding; or Voyage 4 / Cohere Embed v4 managed. Claude via official SDK; stream to React via Vercel AI SDK v6 useChat (SSE).

### Observability
**Pick:** Self-hosted Grafana stack (Loki+Prometheus/VictoriaMetrics+Alloy) OR Grafana Cloud Free, + Bugsink/GlitchTip for errors, + Uptime Kuma for uptime

Enriches her existing monitoring-setup skill. Grafana Cloud Free is only 14-day retention for all signals (30-day/13-month is PRO) — self-host if she needs longer. Errors: Bugsink or GlitchTip 5.2 (now Postgres-only, ~256MB, so footprint-competitive). Uptime: self-host Uptime Kuma — UptimeRobot's free tier banned commercial use since Dec 2024 and is 5-min interval. VictoriaMetrics is lighter than Prometheus but ~1.7-2.5x, not 7x.

### i18n / localization
**Pick:** next-intl for App Router; Paraglide JS v2 for Vite SPAs; git-JSON + AI-draft + human review; optional self-hosted Tolgee

next-intl is the maintained de-facto App Router lib (precompile:true in 4.8 cuts ~9KB; handles Next 16 middleware→proxy.ts). Paraglide for Vite (MIT) but NOT for Next — it bundles all locales with no lazy-loading (size scales with locale count). Tolgee is open-core (Apache-2.0 core + proprietary EE), not pure Apache — strip ee/ for a clean build. Add hreflang with absolute URLs + self-reference.

### CMS / content
**Pick:** Velite + @next/mdx + next-intl (git-based MDX); self-host Payload 3 into the same Next app on her Postgres when a non-dev editor appears

Git-MDX keeps content in-EU, AI-agent-editable, zero SaaS seats. Velite 0.4.0 + Zod completeness checks per locale. Contentlayer is abandoned — use Velite/Content Collections. When an editor needs a UI, Payload 3 installs into Next with one command (Drizzle via @payloadcms/db-postgres, self-hosted, no per-seat fees). Avoid Contentful/Sanity per-seat SaaS for a trilingual solo site.

### Feature flags
**Pick:** Self-hosted Unleash OSS; app-layer canary via flag rollout

Unleash OSS self-hosts on Coolify with correct SDKs for Node/Python. Flipt is also viable but know v2 is Git-native and Fair Core License (source-available, converts to MIT after 2yr), NOT OSS-on-release; the old 'single binary, no DB, MIT' profile is v1. Do canary as a flag rollout % at the app layer — simpler than infra canary on a single host.

### Email / transactional
**Pick:** Resend (with a signed DPA + SCCs) as default; MailPace (EU-hosted, France) if true EU residency is required

Resend's eu-west-1 region ONLY changes mail dispatch — account data, logs, metadata stay in the US, so it does NOT give EU data residency (a real GDPR gap for her). Set up SPF+DKIM(TXT)+DMARC alignment, RFC 8058 one-click unsubscribe, Postgres suppression table, Cloudflare DNS proxy=off. Monitor with Postmaster Tools v2 (no Reputation dashboard anymore — Spam Rate/Compliance/FBL/Auth only). For OTP use Twilio Verify / Vonage Verify.

### Backup & DR
**Pick:** Logical pg_dump --format=custom to Hetzner Object Storage + offen/docker-volume-backup; restic copy-2 to a Hetzner Storage Box; pgBackRest for PITR when she needs sub-dump RPO

pgBackRest was REVIVED and unarchived 18 May 2026 (six-sponsor coalition, original maintainer back) — it's a valid PITR choice again; the 'it's dead, use WAL-G' framing is stale. Hetzner Object Storage is a flat €4.99/mo bundle (1TB storage + 1TB egress), not '€5.99/TB'. Coolify native backups are pg_dump only (no WAL/PITR, no volume backup) with daily/weekly/monthly presets (hourly needs custom cron). Back up /data/coolify too. 3-2-1 + scheduled restore drills.

### Auth (existing skill)
**Pick:** Keep her existing auth-flow skill; payments entitlement checks must be server-only and read from the syncBillingState() Postgres source of truth

No change to auth stack; the payments skill must integrate with auth-flow for server-side entitlement gating (never trust client). Single idempotent syncBillingState() as the one source of truth, signature-verified deduped webhooks.
